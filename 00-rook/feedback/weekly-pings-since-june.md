## Reproducible SQL

Responder-week rows:

```sql
SELECT date_trunc('week', sent_at)::date AS week_start, responder, COUNT(*) AS pings, COUNT(*) FILTER (WHERE outcome = 'taken') AS taken FROM rook.pings WHERE sent_at >= TIMESTAMP '2026-06-01' GROUP BY 1, 2 ORDER BY 1, 2
```

Date comparison (queried separately because weekly aggregates cannot split the release week):

```sql
SELECT CASE WHEN sent_at < TIMESTAMP '2026-08-12' THEN 'Before: 29 June–11 August' WHEN sent_at < TIMESTAMP '2026-08-13' THEN 'Release day: 12 August' ELSE 'After: 13 August–6 September' END AS period, COUNT(*) AS pings, COUNT(*) FILTER (WHERE outcome = 'taken') AS taken FROM rook.pings WHERE sent_at >= TIMESTAMP '2026-06-01' GROUP BY 1 ORDER BY MIN(sent_at)
```
